# Omni work in Pod

This file is a discovery stub. The full guide is served by the `orca` binary:

```sh
orca skills get ae-omni
```

Load it when your repo role is omni, a task mentions Omni topics, measures, views or
dashboards, or dbt columns need exposing in Omni. The guide covers model branches
named after the worktree, editing through the Omni CLI, validation, commits and the
report a reviewer needs.
