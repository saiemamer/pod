Push the branch contents to git and create or update a pull request. The backend automatically detects whether the git branch already exists: if not, it creates a new git branch and opens a PR; if it does, it commits the latest model contents to the existing branch (updating the open PR).

Usage:
  omni models commit <modelid> [flags]

Flags:
      --body string   request body as JSON string, or "-" for stdin
  -h, --help          help for commit

Global Flags:
      --base-url string   API base URL (overrides profile)
      --compact           compact JSON output (no indentation)
  -o, --format string     output format: json, human, auto (default auto: human on TTY, json when piped)
  -p, --profile string    config profile to use
      --token string      API token (overrides profile/env)
