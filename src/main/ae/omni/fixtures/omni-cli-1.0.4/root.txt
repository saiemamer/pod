Omni CLI — programmatic access to the Omni API

Usage:
  omni [command]

Available Commands:
  agent-help      Print agent-oriented usage guide
  ai              AI commands
  api-tokens      API Tokens commands
  completion      Generate the autocompletion script for the specified shell
  config          Manage CLI configuration profiles
  connections     Connections commands
  content         Content commands
  dashboards      Dashboards commands
  documents       Documents commands
  embed           Embed commands
  folders         Folders commands
  help            Help about any command
  labels          Labels commands
  models          Models commands
  query           Query commands
  schedules       Schedules commands
  scim            SCIM commands
  unstable        Unstable commands
  uploads         Uploads commands
  user-attributes User Attributes commands
  users           Users commands

Flags:
      --base-url string   API base URL (overrides profile)
      --compact           compact JSON output (no indentation)
  -o, --format string     output format: json, human, auto (default auto: human on TTY, json when piped)
  -h, --help              help for omni
  -p, --profile string    config profile to use
      --token string      API token (overrides profile/env)
  -v, --version           version for omni

Use "omni [command] --help" for more information about a command.
