Manage CLI configuration profiles

Usage:
  omni config [command]

Available Commands:
  init        Create a new configuration profile
  login       Log in via OAuth browser flow
  logout      Clear OAuth tokens from a profile
  set-format  Set the default output format
  show        Display current configuration
  use         Switch the default profile

Flags:
  -h, --help   help for config

Global Flags:
      --base-url string   API base URL (overrides profile)
      --compact           compact JSON output (no indentation)
  -o, --format string     output format: json, human, auto (default auto: human on TTY, json when piped)
  -p, --profile string    config profile to use
      --token string      API token (overrides profile/env)

Use "omni config [command] --help" for more information about a command.
