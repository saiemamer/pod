List models

Usage:
  omni models list [flags]

Flags:
      --basemodelid string      Filter by base model ID
      --connectionid string     Filter by connection ID
      --cursor string           Cursor for pagination
  -h, --help                    help for list
      --include string          Comma-separated list of fields to include (e.g., activeBranches)
      --includedeleted string   Include deleted models [0, 1, true, false]
      --modelid string          Filter by specific model ID
      --modelkind string        Filter by model kind [SCHEMA, SHARED, SHARED_EXTENSION, BRANCH, WORKBOOK, QUERY]
      --name string             Filter by model name
      --pagesize string         Number of results per page
      --sortdirection string    Sort direction [asc, desc]
      --sortfield string        Field to sort by [name, modelKind, connectionId, baseModelId, createdAt, updatedAt]

Global Flags:
      --base-url string   API base URL (overrides profile)
      --compact           compact JSON output (no indentation)
  -o, --format string     output format: json, human, auto (default auto: human on TTY, json when piped)
  -p, --profile string    config profile to use
      --token string      API token (overrides profile/env)
